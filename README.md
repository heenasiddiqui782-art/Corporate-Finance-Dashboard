# 📊 Corporate Financial Performance Dashboard

Welcome to the **Corporate Financial Performance Dashboard** repository! 

This project features a comprehensive and interactive Excel-based financial dashboard developed for **NimbusEdge Technologies** to track, analyze, and visualize corporate financial metrics across **FY2024 - FY2025**. 

It provides executive leadership and finance teams with a high-level view of the company's financial health, aggregating data across multiple regions, departments, and product categories to deliver actionable insights.

## 🚀 Project Overview

The primary file in this repository is `Corporate_Financial_Performance_Dashboard.xlsx`. This comprehensive workbook takes raw transactional financial data and transforms it into an easy-to-read, visually engaging executive dashboard. It is designed to track Actual vs. Budget performance, monitor profit margins, and manage working capital efficiently.

### 🔑 Key Performance Indicators (KPIs) Tracked:
* **Total Revenue:** ~$14.6M
* **Gross Profit:** ~$10.6M
* **EBITDA:** ~$6.2M
* **Net Profit:** ~$4.0M
* **Gross Margin %:** 72.7%
* **Net Margin %:** 27.7%

## ✨ Key Features & Visualizations

### 1. Revenue, Cost & Profitability Trends
* **Monthly Revenue (Actual vs Budget):** Line chart tracking monthly performance and revenue variance.
* **Profitability Trend:** Multi-line chart comparing Gross Profit, EBITDA, and Net Profit month-over-month.

### 2. Region, Department & Working Capital Analysis
* **Region-wise Revenue:** Bar chart comparing revenue generation across North America and Europe.
* **Department-wise Total Cost:** Bar chart breaking down expenses by departments (Customer Success, Marketing, etc.).
* **Product-wise Net Profit:** Analysis of profitability by offering (Add-on Services vs. Professional Services).
* **Working Capital, AR & AP Trend:** Line chart monitoring the liquidity pipeline (Accounts Receivable, Accounts Payable, and Overall Working Capital).

## 📂 Workbook Structure- https://1drv.ms/x/c/1790eeaed48175a5/IQD_LnN7WSMHR7J-GpfxCqtgATqC57-MPUZzHYNQ6ebTXPg?e=AZT8lz

The `Corporate_Financial_Performance_Dashboard.xlsx` file is organized into several highly functional sheets:

1. **`Dashboard`**: The main interactive interface with dynamic charts and KPI cards.
2. **`Raw_Data`**: The underlying dataset containing transactional records categorized by Date, Region, Department, Product, Cost Center, Revenue, COGS, etc.
3. **`Revenue_Analysis`**: Computes Actual vs. Budgeted Revenue, Revenue Variance, and Month-over-Month (MoM) Growth.
4. **`Cost_Analysis`**: Breaks down Operating Expenses, COGS, Total Cost, and Cost Growth.
5. **`Profitability`**: Calculates EBITDA, Net Profit, EBITDA Margin %, and Net Margin %.
6. **`Budget_vs_Actual`**: Deep-dive variance analysis comparing actuals against budgeted figures for both revenue and expenses, including variance status (Favorable/Unfavorable/Mixed).
7. **`Working_Capital`**: Tracks liquidity metrics including Accounts Receivable, Accounts Payable, Cash Balance, Days Sales Outstanding (DSO), and Days Payable Outstanding (DPO).
8. **`KPI_Summary`**: Aggregates the 24-month data across all segments to provide the final snapshot of the company's financial standing.

## 📥 How to Use

1. **Open the File:**
   Locate and open the `Corporate_Financial_Performance_Dashboard.xlsx` file in Microsoft Excel (Office 365 or Excel 2019+ recommended for best compatibility).
2. **Interact:**
   Navigate to the `Dashboard` tab to view the main visualizations. You can explore the supporting tabs to see how the data is aggregated and calculated.
